# TripHelper Style Preview Catalog

這個目錄保存 TripHelper Next 各風格的實際瀏覽器截圖，方便新增行程前直接比較。可雙擊開啟 `index.html` 瀏覽視覺目錄，再把選定的 style ID 傳給 `scripts/trip-page.py create --style`。

## 使用方式

```powershell
python scripts/trip-page.py create `
  --id 20290405-jeju `
  --name "濟州春日旅行" `
  --short-name "濟州旅行" `
  --start-date 2029-04-05 `
  --end-date 2029-04-08 `
  --style berry-picnic
```

預覽圖不是 PWA 執行期資產，不要加入 manifest 或 service worker cache。24 套風格每次調整共享 token 後，都應重新產生完整三件組：

- `mobile-light.png`
- `desktop-light.png`
- `mobile-dark.png`（有保存深色預覽時）
