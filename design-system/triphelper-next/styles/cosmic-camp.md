# Cosmic Camp / 宇宙露營

- Style ID：`cosmic-camp`
- 適用：觀星、天文館、科技館、太空展、科學營與親子夜遊。
- 感受：在星球之間搭帳篷，兼具科學探索與卡通冒險的未來感。
- Light：paper `#EEF0FF`、ink `#252747`、primary `#5042A8`、pink `#BA3F75`、yellow `#F0C34A`。
- Dark：paper `#09091D`、ink `#F5F2FF`、primary `#9D91FF`、pink `#FF78B0`。
- 元件：星雲漸層、行星軌道、星點底紋、太空艙切角與發光邊框。
- 避免：無限閃爍、純裝飾粒子遮住內容、霓虹文字降低可讀性。
