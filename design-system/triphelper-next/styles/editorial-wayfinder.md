# Editorial Wayfinder / 城市編輯風

- Style ID：`editorial-wayfinder`
- 適用：城市散步、跨區交通、親子綜合與資訊密集行程。
- 感受：紙本行程單、車站導引、編輯排版；俐落但不冷淡。
- Light：paper `#F3F0E8`、ink `#171717`、primary `#2457D6`、signal `#B94124`、highlight `#D9EF57`。
- Dark：paper `#101318`、ink `#F6F2E9`、primary `#7DA2FF`、signal `#FF7958`。
- 元件：壓縮粗體 hero、圓形日期軌道、鈷藍下一站卡、硬邊偏移陰影。
- 避免：把每段內容都包成卡片、旅遊照片 hero、玻璃擬態。
