# Bund Wonderland / 外灘樂遊

- Style ID：`bund-wonderland`
- 適用：上海、江南古鎮、主題樂園、外灘夜景與親子城市行。
- 感受：黛藍夜空、豫園朱紅、燈籠金；Hero 底部是抽象天際線剪影與雙球塔，頂端一串燈籠，保留雲朵繪本的大圓角卡片。
- 來源：由 `cloud-storybook` 複製後調整；token 位於 `templates/trip-pwa/styles.css` 的 `data-style="bund-wonderland"` 三個區塊。
- Light：paper `#FDF6EC`、surface `#FFFFFF`、ink `#1B2340`、primary `#1F3A73`、signal `#B3322A`、highlight `#F0B429`。
- Dark：paper `#0E1326`、surface `#1A2139`、ink `#F6EFE3`、primary `#93B4FF`、signal `#FF8D78`、highlight `#F5C451`。
- 元件：天際線場景 Hero、燈籠串點綴、黛藍→朱紅下一站卡、燈籠金硬陰影與圓形時間線節點。
- 避免：照抄真實地標或樂園品牌圖像、紅金大面積堆疊造成低對比、無限動畫與外部字型。
