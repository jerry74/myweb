# Doodle Notebook / 塗鴉手帳

- Style ID：`doodle-notebook`
- 適用：校外旅行、市集、DIY、親子自由行、文具採買與隨性散步。
- 感受：旅行剪貼簿、螢光筆塊、紙膠帶與手繪路線；每一段行程像剛貼進筆記本的彩色小卡。
- Light：paper `#FFF8DF`、ink `#223344`、primary `#2B65A0`、signal `#E35D43`、highlight `#F4C947`。
- Dark：paper `#171A22`、ink `#FFF4DD`、primary `#82C9FF`、signal `#FF9078`。
- 元件：斜向剪貼底紋、彩色筆刷 Hero、波浪塗鴉路線、紙膠帶感日期軌與硬陰影卡片。
- 避免：難讀的真手寫字、隨機旋轉正文、密集塗鴉與只靠線條顏色傳達狀態。
