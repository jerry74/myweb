# Doodle Notebook / 塗鴉手帳

- Style ID：`doodle-notebook`
- 適用：校外旅行、市集、DIY、親子自由行、文具採買與隨性散步。
- 感受：隨身筆記本、鉛筆格線與手繪框線；親近、自由、有旅行紀錄感。
- Light：paper `#F7F3E7`、ink `#202B38`、primary `#245A86`、signal `#39704B`、highlight `#E6BD3F`。
- Dark：paper `#161A20`、ink `#F6F0DF`、primary `#85BDEA`、signal `#8BD09E`。
- 元件：方格紙底紋、虛線框、不對稱圓角、手寫感系統字體 fallback 與輕硬陰影。
- 避免：難讀的真手寫字、隨機旋轉正文、密集塗鴉與只靠線條顏色傳達狀態。
