# Neon Metro / 都會霓虹

- Style ID：`neon-metro`
- 適用：夜間城市、購物、美食、演唱會、展演與大眾運輸密集行程。
- 感受：紫紅漸層、青綠高光、霓虹街廓與發光路線；像夜裡一路亮著的城市導航。
- Light：paper `#F3F0FF`、ink `#17132D`、primary `#6038D5`、signal `#C62561`、highlight `#4CD7C0`。
- Dark：paper `#090713`、ink `#F0ECFF`、primary `#A98CFF`、signal `#FF5B93`。
- 元件：霓虹樓群 Hero、光帶路線、切角日期章、發光下一站卡與高對比資訊卡。
- 避免：glitch、CRT 掃描線、持續霓虹閃爍與大面積純黑白高刺激對比。
