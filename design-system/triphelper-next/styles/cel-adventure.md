# Cel Adventure / 動畫冒險

- Style ID：`cel-adventure`
- 適用：自駕、戶外探索、家庭旅行、海陸移動與主題式冒險。
- 感受：賽璐璐動畫的俐落色塊、朝氣與前進感；清爽、勇敢、有方向。
- Light：paper `#EAF8F4`、ink `#153B3D`、primary `#147D82`、signal `#B84420`、highlight `#F4C34B`。
- Dark：paper `#101C1D`、ink `#EFFBF5`、primary `#72D6D0`、signal `#FF8C68`。
- 元件：斜向色帶、幾何切角、不對稱節點、青綠主卡與橘色硬陰影。
- 避免：長時間連續動畫、過度漸層、低對比天空色與大型插畫遮蔽資訊。
