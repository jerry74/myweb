# Forest Fairytale / 森林童話

- Style ID：`forest-fairytale`
- 適用：親子森林、童話村、動物園、露營、木屋與自然學習。
- 感受：樹冠、蘑菇與小徑組成柔軟繪本，溫暖可愛但保持資訊清楚。
- Light：paper `#F1F8DF`、ink `#26351F`、primary `#47712F`、berry `#A83E4A`、yellow `#E6BB45`。
- Dark：paper `#111D0E`、ink `#F4F9E8`、primary `#91D36F`、berry `#FF8994`。
- 元件：樹冠剪影、蘑菇圓點、葉片節點、柔軟不對稱圓角與林地陰影。
- 避免：未授權童話角色、過度幼兒化字體、綠色正文對比不足。
