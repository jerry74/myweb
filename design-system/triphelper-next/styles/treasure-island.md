# Treasure Island / 尋寶海島

- Style ID：`treasure-island`
- 適用：海島跳島、船旅、親子探險、尋寶闖關與海岸公路。
- 感受：一張會動的手繪海圖，從虛線航線一路找到島嶼與寶藏。
- Light：paper `#FFF4D7`、ink `#31352B`、primary `#176D72`、signal `#A74632`、gold `#E4B334`。
- Dark：paper `#171B16`、ink `#FFF7DF`、primary `#66D5D2`、signal `#FF8D72`。
- 元件：海圖波紋、島嶼輪廓、航線虛線、羅盤圓章與地圖摺角卡片。
- 避免：骷髏或武器圖案、細線地圖干擾正文、只為造型犧牲點擊區域。
