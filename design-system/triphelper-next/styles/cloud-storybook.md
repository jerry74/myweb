# Cloud Storybook / 雲朵繪本

- Style ID：`cloud-storybook`
- 適用：親子、主題樂園、動物園、水族館與童話小鎮。
- 感受：藍天、雲朵、繪本封面；親切、有想像力但不幼兒化。
- Light：paper `#F0F8FF`、ink `#173451`、primary `#2369A8`、signal `#A84427`、highlight `#F2C94C`。
- Dark：paper `#0C1B2B`、ink `#EEF8FF`、primary `#78BFFF`、signal `#FF9573`。
- 元件：雙圓雲朵底紋、繪本粗標、暖黃硬陰影與不對稱大圓角。
- 避免：角色插圖依賴、跳動元件、低對比嬰兒藍文字。
