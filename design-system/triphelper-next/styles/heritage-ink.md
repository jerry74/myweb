# Heritage Ink / 文化紙本

- Style ID：`heritage-ink`
- 適用：古城、寺社、博物館、歷史街區、鐵道與慢旅行。
- 感受：文化手冊、館藏標籤、宣紙與棕墨；沉靜、節制、耐讀。
- Light：paper `#F1E8D8`、ink `#2B211B`、primary `#76523B`、signal `#9F4029`、highlight `#C6AA50`。
- Dark：paper `#1B1512`、ink `#F1E8DC`、primary `#D7AD86`、signal `#EF8062`。
- 元件：細直紋紙面、Georgia 襯線 hero、低圓角、方形節點與館藏卡片式陰影。
- 避免：仿古裝飾堆疊、難讀書法字體、低對比棕色正文。
