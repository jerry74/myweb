# Berry Picnic / 莓果野餐

- Style ID：`berry-picnic`
- 適用：花季、農場、野餐、鄉村、溫泉與輕旅行。
- 感受：莓果果醬、餐巾格紋、花園與奶油紙張；柔和、自然、溫暖。
- Light：paper `#FFF8F0`、ink `#3E2A35`、primary `#7F2D4F`、signal `#2F6B4F`、highlight `#EDC34E`。
- Dark：paper `#25171E`、ink `#FFF2F4`、primary `#F38CB6`、signal `#8BD3AA`。
- 元件：低彩格紋、莓果漸層、不對稱圓角、柔和陰影與圓形時間線節點。
- 避免：裝飾花朵覆蓋文字、低對比粉綠組合與大量材質圖片。
