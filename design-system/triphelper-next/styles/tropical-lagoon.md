# Tropical Lagoon / 熱帶潟湖

- Style ID：`tropical-lagoon`
- 適用：峇里島、衝浪、沙灘、渡假村與熱帶放鬆行程。
- 感受：潟湖、棕櫚、日光與沙洲；明快、清爽並帶悠閒海島節奏。
- Light：paper `#EAF9F6`、ink `#12353D`、primary `#08717D`、signal `#B94C35`、highlight `#D6AA35`。
- Dark：paper `#071D21`、ink `#EEFCF9`、primary `#64D6DC`、signal `#FF9474`。
- 元件：水滴點紋、日光潟湖 Hero、沙洲與波紋場景、膠囊日期、圓形節點及流線不對稱卡。
- 避免：與珊瑚潛旅使用相同海底語彙、玻璃透明卡、持續波浪動畫與低對比薄荷色正文。
