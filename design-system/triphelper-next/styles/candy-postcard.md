# Candy Postcard / 糖果明信片

- Style ID：`candy-postcard`
- 適用：咖啡甜點、閨蜜旅行、購物、拍照景點與療癒系小旅行。
- 感受：莓粉、紫色、糖果圓點與泡泡場景；每張資訊卡像貼在明信片上的甜點貼紙。
- Light：paper `#FFF3F8`、ink `#4A1734`、primary `#9D2C67`、signal `#694092`、highlight `#F2C94C`。
- Dark：paper `#24131D`、ink `#FFF1F7`、primary `#FF91C4`、signal `#C9A2F2`。
- 元件：泡泡與糖果場景 Hero、彩色圓章、雙色 CTA、圓形節點與厚實柔和陰影。
- 避免：粉色文字配粉色背景、閃爍亮粉、愛心或 emoji 當功能圖示。
