# Sticker Playground / 貼紙玩樂

- Style ID：`sticker-playground`
- 適用：樂園、追星、動漫、快閃店、青春城市與好友旅行。
- 感受：貼紙手帳、票根、彩色膠帶；活潑、有個性、帶一點 ugly-cute。
- Light：paper `#FFF8D9`、ink `#1C1A23`、primary `#CF2862`、signal `#176486`、highlight `#FFD447`。
- Dark：paper `#17141D`、ink `#FFF9DF`、primary `#FF74A7`、signal `#73CBED`。
- 元件：幾何點線底紋、粗框、虛線日期軌道、硬陰影與方形路線節點。
- 避免：隨機旋轉文字、跑馬燈、glitch、動畫貼紙或失控的 maximalism。
