# Tokyo Pulse / 東京潮流

- Style ID：`tokyo-pulse`
- 適用：東京夜景、動漫、購物、科技、美食與高密度都會旅行。
- 感受：霓虹街廓、十字路口、數位招牌與電車脈動；快速、鮮明且帶未來感。
- Light：paper `#E9F7FB`、ink `#132A3B`、primary `#075D80`、signal `#B82770`、highlight `#16A9AD`。
- Dark：paper `#050D1D`、ink `#F5FBFF`、primary `#49D9E6`、signal `#FF5DB4`。
- 元件：城市網格、午夜藍到霓虹粉 Hero、街廓色塊、斜切圓角、青色描邊與粉青漸層日期圖章。
- 避免：未授權動漫角色、持續霓虹閃爍、glitch 干擾閱讀與把所有資訊都做成高飽和招牌。
