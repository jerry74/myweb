# Golden Boulevard / 金色街廓

- Style ID：`golden-boulevard`
- 適用：巴黎、歐洲古都、咖啡館、建築、藝術與街區散步。
- 感受：午後金光、林蔭大道、街角店舖與老城石材；優雅、溫暖且富有生活感。
- Light：paper `#FFF6E8`、ink `#34261C`、primary `#925008`、signal `#9B3930`、highlight `#D7A831`。
- Dark：paper `#24180F`、ink `#FFF5E8`、primary `#F1AE55`、signal `#FF8978`。
- 元件：街廓格線、蜂蜜金 Hero、店舖與遮棚場景、雙線膠囊日期、典雅襯線標題與斜角圓卡。
- 避免：奢華金屬漸層、過細裝飾線、仿製特定地標插畫與用低對比棕金承載小字。
