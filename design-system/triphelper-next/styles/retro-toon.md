# Retro Toon / 復古卡通

- Style ID：`retro-toon`
- 適用：老街、鐵道、懷舊餐廳、公路旅行、古董市集與慢節奏城市。
- 感受：中世紀卡通海報、舊式餐館與膠囊招牌；溫暖、俏皮、帶年代感。
- Light：paper `#F8EED8`、ink `#30251F`、primary `#146B70`、signal `#A33F2B`、highlight `#D7B64A`。
- Dark：paper `#1D1815`、ink `#F8EED8`、primary `#74C9C7`、signal `#F08A6D`。
- 元件：橢圓點紋、雙線邊框、膠囊日期、奶油紙與珊瑚硬陰影。
- 避免：做舊到降低閱讀性、仿品牌角色、過細裝飾線與褪色低對比文字。
