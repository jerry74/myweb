# Coastal Breeze / 海島微風

- Style ID：`coastal-breeze`
- 適用：海島、海灘、郵輪、渡假村與親子放鬆行程。
- 感受：海風、淺水、沙灘與珊瑚；明亮、柔和但不幼稚。
- Light：paper `#EDF8FA`、ink `#123548`、primary `#087E9B`、signal `#B74627`、highlight `#F2C852`。
- Dark：paper `#071B23`、ink `#EEFBFD`、primary `#5FD5EA`、signal `#FF8B68`。
- 元件：點狀潮汐底紋、不對稱圓角、海水漸層下一站卡、柔和浮起陰影。
- 避免：低對比粉彩文字、大面積動畫波浪與玻璃透明卡。
