# Ancient Odyssey / 古文明漫遊

- Style ID：`ancient-odyssey`
- 適用：古羅馬、希臘、考古遺址、博物館與文明巡禮。
- 感受：石柱、廣場、羊皮紙與考古圖錄；典雅、有歷史重量但不顯沉悶。
- Light：paper `#FFF3D8`、ink `#2F241C`、primary `#825316`、signal `#99412E`、highlight `#D5A83B`。
- Dark：paper `#21170F`、ink `#FFF0D3`、primary `#D7953C`、signal `#E37857`。
- 元件：石紋菱格底紋、暖金遺址 Hero、柱廊幾何場景、雙線邊框、拱門日期與襯線標題。
- 避免：仿舊污漬壓過內容、過細襯線正文、滿版浮雕裝飾與把文化意象簡化成刻板角色。
