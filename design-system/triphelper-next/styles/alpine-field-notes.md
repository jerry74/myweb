# Alpine Field Notes / 山野手帳

- Style ID：`alpine-field-notes`
- 適用：自駕、登山、露營、健行、國家公園與自然觀察。
- 感受：野外筆記、森林路標、地形圖；安定、耐讀、略帶手作感。
- Light：paper `#F0F2E7`、ink `#1D2A21`、primary `#2F6845`、signal `#A84F2D`、highlight `#D3B94B`。
- Dark：paper `#111A14`、ink `#EEF2E9`、primary `#89C99F`、signal `#EF8B5F`。
- 元件：筆記橫線、Georgia 襯線 hero、方形節點、對角圓角與實體紙卡陰影。
- 避免：螢光綠、複雜有機動畫、仿木紋照片背景。
