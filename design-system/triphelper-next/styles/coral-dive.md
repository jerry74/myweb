# Coral Dive / 珊瑚潛旅

- Style ID：`coral-dive`
- 適用：潛水、浮潛、珊瑚礁、海洋生態與海島探險。
- 感受：清澈海水、氣泡、珊瑚與熱帶魚群；輕盈、鮮活且有下潛深度。
- Light：paper `#E8F9F8`、ink `#123542`、primary `#0B7182`、signal `#C75449`、highlight `#1AA7A3`。
- Dark：paper `#061B24`、ink `#EDFFFF`、primary `#45D0C7`、signal `#FF8879`。
- 元件：氣泡點紋、海水縱深 Hero、珊瑚礁弧形場景、圓形日期、礁石節點與波浪式不對稱卡片。
- 避免：過度寫實海洋生物、氣泡持續漂浮、透明卡降低文字對比與只靠藍綠色區分狀態。
