# Nordic Fjord / 北歐峽灣

- Style ID：`nordic-fjord`
- 適用：挪威峽灣、公路旅行、瀑布、木屋、健行與郵輪。
- 感受：冰河空氣、深谷與極簡北歐明信片，安靜但不冷淡。
- Light：paper `#EDF7F5`、ink `#17363B`、primary `#17666C`、signal `#A5473C`、highlight `#D8BD48`。
- Dark：paper `#091B1D`、ink `#EFFCF9`、primary `#67D0D0`、signal `#FF8F7E`。
- 元件：分層雪峰、峽灣水面、瀑布直線、交錯圓角與乾淨留白。
- 避免：大量純白造成眩光、與極光冰原共用星空主視覺。
