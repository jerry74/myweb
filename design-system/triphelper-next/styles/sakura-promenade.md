# Sakura Promenade / 櫻花漫遊

- Style ID：`sakura-promenade`
- 適用：賞櫻、寺社、春日街區、和風散步與花季旅行。
- 感受：櫻花步道、鳥居、春芽與柔風；溫柔、明亮又保留清楚的旅行導引。
- Light：paper `#FFF4F3`、ink `#2F2530`、primary `#9D3E5B`、signal `#A43731`、highlight `#D7AA31`。
- Dark：paper `#24171C`、ink `#FFF3F5`、primary `#FF8FA9`、signal `#F27F78`。
- 元件：花瓣點紋、粉綠漸層 Hero、鳥居與花樹場景、花瓣日期與節點、柔和不對稱圓角卡。
- 避免：粉彩文字對比不足、落花無限動畫、直接描摹特定寺社插畫與把所有分類都做成相近粉色。
