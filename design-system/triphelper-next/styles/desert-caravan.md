# Desert Caravan / 沙漠星旅

- Style ID：`desert-caravan`
- 適用：摩洛哥、沙漠露營、古城、駱駝旅程與香料市集。
- 感受：白天是香料暖橘與層疊沙丘，深色模式轉為靛青星空與營地火光。
- Light：paper `#FFF1D8`、ink `#3B281D`、primary `#8B451F`、indigo `#4C4C91`、highlight `#E3AD38`。
- Dark：paper `#22150D`、ink `#FFF1D9`、primary `#F0A05C`、indigo `#AAA1F0`。
- 元件：沙丘場景、帳篷剪影、星點底紋、不對稱拱形卡與香料色硬陰影。
- 避免：低對比黃字、寫實文化符號、把沙色用成整頁同色塊。
