# 2026 沖繩親子行程

- 日期：2026/05/30 - 2026/06/06
- 航班：NU302 / NU301
- 租車：5/31 開始
- 雨天核心：水族館・文化王國・Costco

## 每日行程

### Day 1｜5/30（六）抵達那霸，不租車

- 住宿：沖繩那霸柔婕閣酒店（La'gent Hotel Okinawa Naha）
- 早餐準備：依照當天住宿與前一站行程彈性準備早餐。
- 雨天備案：這天不排戶外遠點；若下雨，直接縮短國際通散步，改成飯店休息與便利店採買。

#### 時間軸

- **中午**：抵達那霸機場（Naha Airport / 那覇空港），進市區入住休息。（[Google Maps](https://www.google.com/maps/search/?api=1&query=Naha%20Airport)）
- **傍晚**：國際通（Kokusai Street / 国際通り）散步，可順路看第一牧志公設市場；若想吃海鮮可改泊港漁市場，再晚餐與採買隔天早餐。（[地圖](https://www.google.com/maps/search/?api=1&query=Kokusai%20Dori%20Naha) / [中文攻略](https://edgechen.photography/kokusai-dori/) / [第一牧志公設市場](https://www.google.com/maps/search/?api=1&query=Makishi%20Public%20Market%20Naha) / [泊港漁市場](https://www.google.com/maps/search/?api=1&query=Tomari%20Iyumachi%20Fish%20Market%20Naha)）
- **晚上**：平和通商店街（Heiwa-dori / 平和通り）短逛，早點回飯店。（[地圖](https://www.google.com/maps/search/?api=1&query=Heiwa%20dori%20Naha)）

#### 三餐與採買

- **早餐**：飛機上或機場簡單吃。
- **午餐**：抵達後以機場或那霸市區簡餐為主。
- **晚餐**：牛排館 88 國際通店、山地沙丘餐酒館、國際通屋台村、一蘭那霸國際通店、暖暮那霸牧志店、琉家拉麵國際通本店。（[牛排館88地圖](https://www.google.com/maps/search/?api=1&query=Steak%20House%2088%20Kokusai%20Dori) / [牛排館88介紹](https://twobunny.tw/steak-house-88/) / [Sand's 地圖](https://www.google.com/maps/search/?api=1&query=Sand's%20Diner%20Naha) / [Sand's 介紹](https://twobunny.tw/sands-diner/) / [屋台村地圖](https://www.google.com/maps/search/?api=1&query=Kokusai%20Dori%20Yatai%20Mura) / [屋台村介紹](https://mimigo.tw/okinawa-yatai/) / [一蘭那霸國際通店 地圖](https://www.google.com/maps/search/?api=1&query=Ichiran%20Naha%20Kokusai%20Dori) / [一蘭那霸國際通店 介紹](https://ichiran.com/shop/kyushu/naha-kokusaidori/) / [暖暮那霸牧志店 地圖](https://www.google.com/maps/search/?api=1&query=Ramen%20Danbo%20Naha%20Makishi) / [暖暮那霸牧志店 介紹](https://ramendanbo.okinawa/locations-2/) / [琉家拉麵國際通本店 地圖](https://www.google.com/maps/search/?api=1&query=Ramen%20Ryukya%20Kokusai%20Dori%20Naha)）
- **採買**：便利店買飯糰、麵包、優格、牛奶、水果。

### Day 2｜5/31（日）取車，美國村，北上名護

- 住宿：沖繩名護海灘貝斯特韋斯特飯店（Best Western Okinawa Kouki Beach）
- 早餐準備：5/30 那霸便利店買好。
- 雨天備案：小雨照去美國村，以餐廳與室內店鋪為主；大雨就縮短或取消，把美國村移到 6/3 傍晚補。

#### 時間軸

- **上午**：退房後在那霸取車，開始自駕。
- **中午**：美國村（American Village / アメリカンビレッジ）午餐與逛街。（[地圖](https://www.google.com/maps/search/?api=1&query=American%20Village%20Okinawa) / [中文攻略](https://yusuke.com.tw/blog/post/okinawa-american-village)）
- **下午**：視天氣在美國村散步、購物，之後北上名護／幸喜入住。（[幸喜海灘](https://www.google.com/maps/search/?api=1&query=Kouki%20Beach%20Nago%20Okinawa)）
- **雨天**：美國村縮短成吃飯短停；若雨太大，移到 6/3 傍晚補。

#### 三餐與採買

- **早餐**：前一晚便利店早餐。
- **午餐**：和牛咖啡 Kapuka、加州廚房、濱屋沖繩麵、Ishigakijima Kitchen Bin 石垣牛漢堡、暖暮北谷砂辺店、燒肉王北谷店。（[Kapuka 地圖](https://www.google.com/maps/search/?api=1&query=WaGyu%20Cafe%20Kapuka) / [Kapuka 介紹](https://fupo.tw/blog/post/wagyu-cafe-kapuka) / [加州廚房地圖](https://www.google.com/maps/search/?api=1&query=THE%20CALIF%20KITCHEN%20Okinawa) / [加州廚房介紹](https://gogojp.tw/the-calif-kitchen-r/) / [濱屋地圖](https://www.google.com/maps/search/?api=1&query=Hamaya%20Soba%20Okinawa) / [濱屋介紹](https://mimigo.tw/okinawa-americanvillage/) / [Kitchen Bin 地圖](https://www.google.com/maps/search/?api=1&query=Ishigakijima%20Kitchen%20Bin%20Chatan) / [Kitchen Bin 介紹](https://tiffanyscafe.pixnet.net/blog/post/42199858) / [暖暮北谷砂辺店 地圖](https://www.google.com/maps/search/?api=1&query=Ramen%20Danbo%20Chatan%20Sunabe) / [暖暮北谷砂辺店 介紹](https://ramendanbo.okinawa/locations-2/) / [燒肉王北谷店 地圖](https://www.google.com/maps/search/?api=1&query=Yakiniku%20King%20Chatan) / [燒肉王北谷店 介紹](https://www.yakiniku-king.jp/shop/2131/)）
- **晚餐**：AEON 名護購物中心、名護市區簡餐、暖暮名護店或燒肉王名護店，順便補貨。（[AEON 名護地圖](https://www.google.com/maps/search/?api=1&query=AEON%20Nago%20Shopping%20Center) / [官方資訊](https://world.aeon-ryukyu.jp/en/store/aeon/aeon_nago/) / [暖暮名護店 地圖](https://www.google.com/maps/search/?api=1&query=Ramen%20Danbo%20Nago) / [暖暮名護店 介紹](https://ramendanbo.okinawa/locations-2/) / [燒肉王名護店 地圖](https://www.google.com/maps/search/?api=1&query=Yakiniku%20King%20Nago) / [燒肉王名護店 介紹](https://www.yakiniku-king.jp/shop/243/)）

#### 購物備案

- **AEON 北谷店**：適合：超市補貨 / 雨天備案 / 餐廳多。美國村順路，天氣不穩時可改成室內採買與用餐。（[Google Maps](https://www.google.com/maps/search/?api=1&query=AEON%20Chatan%20Okinawa)）
- **AEON 名護**：適合：超市補貨 / 餐廳多 / 雨天備案。抵達名護後補早餐、零食與生活用品最順手。（[Google Maps](https://www.google.com/maps/search/?api=1&query=AEON%20Nago%20Shopping%20Center) / [官方資訊](https://world.aeon-ryukyu.jp/en/store/aeon/aeon_nago/)）

### Day 3｜6/1（一）水族館與海洋博公園

- 住宿：沖繩名護海灘貝斯特韋斯特飯店（Best Western Okinawa Kouki Beach）
- 早餐準備：5/31 AEON 名護或便利店買好。
- 雨天備案：這天是雨天友善日；下雨時保留水族館，縮短海洋博公園戶外散步。

#### 時間軸

- **上午**：沖繩美麗海水族館（Okinawa Churaumi Aquarium / 沖縄美ら海水族館），停留 2.5 到 3 小時。（[地圖](https://www.google.com/maps/search/?api=1&query=Okinawa%20Churaumi%20Aquarium) / [中文攻略](https://okinawa.letsgojp.com/archives/17071/)）
- **中午**：海洋博公園（Ocean Expo Park / 海洋博公園）周邊午餐。（[地圖](https://www.google.com/maps/search/?api=1&query=Ocean%20Expo%20Park%20Okinawa)）
- **下午**：海洋博公園散步，雨天縮短戶外，水族館照跑。
- **晚上**：回名護／幸喜晚餐、休息。

#### 三餐與採買

- **早餐**：前一晚採買。
- **午餐**：園區或周邊簡單吃；若想專程吃好一點，可選燒肉本部牧場本部總店或 Captain Kangaroo Hamburger。（[燒肉本部牧場本部總店 地圖](https://www.google.com/maps/search/?api=1&query=Yakiniku%20Motobu%20Farm%20Motobu) / [燒肉本部牧場本部總店 介紹](https://motobu-farm.com/pages/store-motobu) / [Captain Kangaroo 地圖](https://www.google.com/maps/search/?api=1&query=Captain%20Kangaroo%20Hamburger%20Motobu) / [Captain Kangaroo 介紹](https://www.facebook.com/captainkangaroo84)）
- **晚餐**：松之古民家、名護牛排、法蘭彼餐廳、AEON 名護、暖暮名護店或燒肉王名護店。（[松之古民家地圖](https://www.google.com/maps/search/?api=1&query=Matsu%20no%20Kominka%20Nago) / [松之古民家介紹](https://twobunny.tw/matsu-no-kominka/) / [名護牛排地圖](https://www.google.com/maps/search/?api=1&query=Nago%20Steak%20Okinawa) / [名護牛排評價](https://www.tripadvisor.com/Restaurant_Review-g1023465-d15710026-Reviews-Nago_Steak-Nago_Okinawa_Prefecture_Kyushu.html) / [Flipper 地圖](https://www.google.com/maps/search/?api=1&query=Restaurant%20Flipper%20Nago) / [Flipper 評價](https://www.tripadvisor.com/Restaurant_Review-g1023465-d1179034-Reviews-Restaurant_Flipper-Nago_Okinawa_Prefecture_Kyushu.html) / [暖暮名護店 地圖](https://www.google.com/maps/search/?api=1&query=Ramen%20Danbo%20Nago) / [暖暮名護店 介紹](https://ramendanbo.okinawa/locations-2/) / [燒肉王名護店 地圖](https://www.google.com/maps/search/?api=1&query=Yakiniku%20King%20Nago) / [燒肉王名護店 介紹](https://www.yakiniku-king.jp/shop/243/)）

#### 購物備案

- **AEON 名護**：適合：超市補貨 / 餐廳多 / 雨天備案。回住宿區前最後補貨點，適合隔天早餐與零食一次買齊。（[Google Maps](https://www.google.com/maps/search/?api=1&query=AEON%20Nago%20Shopping%20Center) / [官方資訊](https://world.aeon-ryukyu.jp/en/store/aeon/aeon_nago/)）

### Day 4｜6/2（二）古宇利島，Neo Park，南下殘波岬

- 住宿：沖繩殘波岬美爵度假酒店（Grand Mercure Okinawa Cape Zanpa Resort / グランドメルキュール沖縄残波岬リゾート）
- 早餐準備：6/1 名護超市或便利店買好。
- 雨天備案：古宇利島最吃天氣；大雨取消古宇利，改以 Neo Park 為主，提早入住飯店。

#### 時間軸

- **上午**：古宇利島（Kouri Island / 古宇利島），晴天停留 1.5 到 2 小時。（[地圖](https://www.google.com/maps/search/?api=1&query=Kouri%20Island%20Okinawa) / [中文攻略](https://www.jeepe.jp/zh_TW/articles/kouri-island-travel-guide-1477)）
- **中午**：古宇利或名護沿線午餐。
- **下午**：名護動植物園（Neo Park Okinawa / ネオパークオキナワ），再南下入住殘波岬。（[地圖](https://www.google.com/maps/search/?api=1&query=Neo%20Park%20Okinawa) / [中文攻略](https://twobunny.tw/neo-park/)）
- **雨天**：古宇利島取消或短停；Neo Park 保留，提早入住飯店。

#### 三餐與採買

- **早餐**：前一晚採買。
- **午餐**：北部簡餐、沖繩麵、咖啡輕食、古宇利蝦蝦飯、Captain Kangaroo Hamburger，或燒肉本部牧場本部總店。（[古宇利蝦蝦飯 地圖](https://www.google.com/maps/search/?api=1&query=Kouri%20Shrimp%20Okinawa) / [古宇利蝦蝦飯 介紹](https://www.gltjp.com/ja/directory/item/14833/) / [Captain Kangaroo 地圖](https://www.google.com/maps/search/?api=1&query=Captain%20Kangaroo%20Hamburger%20Motobu) / [Captain Kangaroo 介紹](https://www.facebook.com/captainkangaroo84) / [燒肉本部牧場本部總店 地圖](https://www.google.com/maps/search/?api=1&query=Yakiniku%20Motobu%20Farm%20Motobu) / [燒肉本部牧場本部總店 介紹](https://motobu-farm.com/pages/store-motobu)）
- **晚餐**：濱之家海鮮料理、金月沖繩麵、將軍漢堡恩納村店。（[濱之家地圖](https://www.google.com/maps/search/?api=1&query=Hamanoya%20Onna%20Okinawa) / [濱之家介紹](https://mimihan.tw/hamanoya/) / [金月地圖](https://www.google.com/maps/search/?api=1&query=Kinjichi%20Soba%20Onna) / [金月介紹](https://tw.ecob.okinawa/okinawa-noodle-kinchichi-onna-tw/) / [將軍漢堡地圖](https://www.google.com/maps/search/?api=1&query=SHOGUN%20BURGER%20Onna) / [將軍漢堡介紹](https://www.markting.com.tw/577/)）

### Day 5｜6/3（三）渡假飯店放空，美國村補位

- 早餐準備：6/2 恩納／讀谷周邊便利店買好。
- 雨天備案：雨天以飯店室內設施、餐廳、休息為主；只有 5/31 沒去成美國村時才補位。

#### 時間軸

- **上午**：飯店泳池、沙灘、親子放空。（[飯店地圖](https://www.google.com/maps/search/?api=1&query=Grand%20Mercure%20Okinawa%20Cape%20Zanpa%20Resort)）
- **中午**：飯店內或讀谷／恩納周邊午餐。
- **下午**：回房午睡或繼續飯店設施。
- **傍晚**：若 5/31 美國村受雨影響，這天補美國村；否則維持純放鬆。（[美國村](https://www.google.com/maps/search/?api=1&query=American%20Village%20Okinawa)）

### Day 6｜6/4（四）回那霸，市區採買

- 住宿：沖繩那霸柔婕閣酒店（La'gent Hotel Okinawa Naha）
- 早餐準備：6/3 恩納／讀谷周邊便利店買好。
- 雨天備案：市區日受雨影響小；下雨就選新都心、DFS、商場、餐廳，縮短國際通戶外步行。

#### 時間軸

- **上午**：退房後自駕回那霸，飯店寄放行李或入住。
- **下午**：新都心（Omoromachi / おもろまち）、DFS 沖繩、國際通、第一牧志公設市場或泊港漁市場擇一到兩個點。（[新都心](https://www.google.com/maps/search/?api=1&query=Omoromachi%20Naha) / [DFS](https://www.google.com/maps/search/?api=1&query=T%20Galleria%20Okinawa%20by%20DFS) / [國際通](https://www.google.com/maps/search/?api=1&query=Kokusai%20Dori%20Naha) / [第一牧志公設市場](https://www.google.com/maps/search/?api=1&query=Makishi%20Public%20Market%20Naha) / [泊港漁市場](https://www.google.com/maps/search/?api=1&query=Tomari%20Iyumachi%20Fish%20Market%20Naha)）
- **晚上**：那霸市區晚餐、採買、整理行李。

#### 三餐與採買
