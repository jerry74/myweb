# 2026 沖繩親子行程

- 日期：2026/05/30 - 2026/06/06
- 航班：NU302 / NU301
- 租車：5/31 開始
- 雨天核心：水族館・文化王國・Costco

## 每日行程

### Day 1｜5/30（六）抵達那霸，不租車

- 住宿：東急 Stay 沖繩那霸（Tokyu Stay Okinawa Naha / 東急ステイ沖縄那覇）
- 早餐準備：依照當天住宿與前一站行程彈性準備早餐。
- 雨天備案：這天不排戶外遠點；若下雨，直接縮短國際通散步，改成飯店休息與便利店採買。

#### 時間軸

- **中午**：抵達那霸機場（Naha Airport / 那覇空港），進市區入住休息。（[Google Maps](https://www.google.com/maps/search/?api=1&query=Naha%20Airport)）
- **傍晚**：國際通（Kokusai Street / 国際通り）散步、晚餐、採買隔天早餐。（[地圖](https://www.google.com/maps/search/?api=1&query=Kokusai%20Dori%20Naha) / [中文攻略](https://edgechen.photography/kokusai-dori/)）
- **晚上**：平和通商店街（Heiwa-dori / 平和通り）短逛，早點回飯店。（[地圖](https://www.google.com/maps/search/?api=1&query=Heiwa%20dori%20Naha)）

#### 三餐與採買

- **早餐**：飛機上或機場簡單吃。
- **午餐**：抵達後以機場或那霸市區簡餐為主。
- **晚餐**：牛排館 88 國際通店、山地沙丘餐酒館或國際通屋台村。（[牛排館88地圖](https://www.google.com/maps/search/?api=1&query=Steak%20House%2088%20Kokusai%20Dori) / [牛排館88介紹](https://twobunny.tw/steak-house-88/) / [Sand's 地圖](https://www.google.com/maps/search/?api=1&query=Sand's%20Diner%20Naha) / [Sand's 介紹](https://twobunny.tw/sands-diner/) / [屋台村地圖](https://www.google.com/maps/search/?api=1&query=Kokusai%20Dori%20Yatai%20Mura) / [屋台村介紹](https://mimigo.tw/okinawa-yatai/)）
- **採買**：便利店買飯糰、麵包、優格、牛奶、水果。

### Day 2｜5/31（日）取車，美國村，北上名護

- 住宿：名護／幸喜住宿（Nago / Kouki / 名護・幸喜）
- 早餐準備：5/30 那霸便利店買好。
- 雨天備案：小雨照去美國村，以餐廳與室內店鋪為主；大雨就縮短或取消，把美國村移到 6/3 傍晚補。

#### 時間軸

- **上午**：退房後在那霸取車，開始自駕。
- **中午**：美國村（American Village / アメリカンビレッジ）午餐與逛街。（[地圖](https://www.google.com/maps/search/?api=1&query=American%20Village%20Okinawa) / [中文攻略](https://yusuke.com.tw/blog/post/okinawa-american-village)）
- **下午**：視天氣散步、購物，之後北上名護／幸喜入住。（[幸喜海灘](https://www.google.com/maps/search/?api=1&query=Kouki%20Beach%20Nago%20Okinawa)）
- **雨天**：美國村縮短成吃飯短停；若雨太大，移到 6/3 傍晚補。

#### 三餐與採買

- **早餐**：前一晚便利店早餐。
- **午餐**：和牛咖啡 Kapuka、加州廚房、濱屋沖繩麵。（[Kapuka 地圖](https://www.google.com/maps/search/?api=1&query=WaGyu%20Cafe%20Kapuka) / [Kapuka 介紹](https://fupo.tw/blog/post/wagyu-cafe-kapuka) / [加州廚房地圖](https://www.google.com/maps/search/?api=1&query=THE%20CALIF%20KITCHEN%20Okinawa) / [加州廚房介紹](https://gogojp.tw/the-calif-kitchen-r/) / [濱屋地圖](https://www.google.com/maps/search/?api=1&query=Hamaya%20Soba%20Okinawa) / [濱屋介紹](https://mimigo.tw/okinawa-americanvillage/)）
- **晚餐**：AEON 名護購物中心或名護市區簡餐，順便補貨。（[AEON 名護地圖](https://www.google.com/maps/search/?api=1&query=AEON%20Nago%20Shopping%20Center) / [官方資訊](https://world.aeon-ryukyu.jp/en/store/aeon/aeon_nago/)）

### Day 3｜6/1（一）水族館與海洋博公園

- 住宿：名護／幸喜住宿（Nago / Kouki / 名護・幸喜）
- 早餐準備：5/31 AEON 名護或便利店買好。
- 雨天備案：這天是雨天友善日；下雨時保留水族館，縮短海洋博公園戶外散步。

#### 時間軸

- **上午**：沖繩美麗海水族館（Okinawa Churaumi Aquarium / 沖縄美ら海水族館），停留 2.5 到 3 小時。（[地圖](https://www.google.com/maps/search/?api=1&query=Okinawa%20Churaumi%20Aquarium) / [中文攻略](https://okinawa.letsgojp.com/archives/17071/)）
- **中午**：海洋博公園（Ocean Expo Park / 海洋博公園）周邊午餐。（[地圖](https://www.google.com/maps/search/?api=1&query=Ocean%20Expo%20Park%20Okinawa)）
- **下午**：海洋博公園散步，雨天縮短戶外，水族館照跑。
- **晚上**：回名護／幸喜晚餐與休息。

#### 三餐與採買

- **早餐**：前一晚採買。
- **午餐**：園區或周邊簡單吃。
- **晚餐**：松之古民家、名護牛排、法蘭彼餐廳，或 AEON 名護。（[松之古民家地圖](https://www.google.com/maps/search/?api=1&query=Matsu%20no%20Kominka%20Nago) / [松之古民家介紹](https://twobunny.tw/matsu-no-kominka/) / [名護牛排地圖](https://www.google.com/maps/search/?api=1&query=Nago%20Steak%20Okinawa) / [名護牛排評價](https://www.tripadvisor.com/Restaurant_Review-g1023465-d15710026-Reviews-Nago_Steak-Nago_Okinawa_Prefecture_Kyushu.html) / [Flipper 地圖](https://www.google.com/maps/search/?api=1&query=Restaurant%20Flipper%20Nago) / [Flipper 評價](https://www.tripadvisor.com/Restaurant_Review-g1023465-d1179034-Reviews-Restaurant_Flipper-Nago_Okinawa_Prefecture_Kyushu.html)）

### Day 4｜6/2（二）古宇利島，Neo Park，南下殘波岬

- 住宿：沖繩殘波岬美爵度假酒店（Grand Mercure Okinawa Cape Zanpa Resort / グランドメルキュール沖縄残波岬リゾート）
- 早餐準備：6/1 名護超市或便利店買好。
- 雨天備案：古宇利島最吃天氣；大雨取消古宇利，改以 Neo Park 為主，提早入住飯店。

#### 時間軸

- **上午**：古宇利島（Kouri Island / 古宇利島），晴天停留 1.5 到 2 小時。（[地圖](https://www.google.com/maps/search/?api=1&query=Kouri%20Island%20Okinawa) / [中文攻略](https://www.jeepe.jp/zh_TW/articles/kouri-island-travel-guide-1477)）
- **中午**：古宇利或名護沿線午餐。
- **下午**：名護動植物園（Neo Park Okinawa / ネオパークオキナワ），再南下入住殘波岬。（[地圖](https://www.google.com/maps/search/?api=1&query=Neo%20Park%20Okinawa) / [中文攻略](https://twobunny.tw/neo-park/)）
- **雨天**：古宇利島取消或短停；Neo Park 保留，提早入住飯店。

#### 三餐與採買

- **早餐**：前一晚採買。
- **午餐**：北部簡餐、沖繩麵或咖啡輕食。
- **晚餐**：濱之家海鮮料理、金月沖繩麵、將軍漢堡恩納村店。（[濱之家地圖](https://www.google.com/maps/search/?api=1&query=Hamanoya%20Onna%20Okinawa) / [濱之家介紹](https://mimihan.tw/hamanoya/) / [金月地圖](https://www.google.com/maps/search/?api=1&query=Kinjichi%20Soba%20Onna) / [金月介紹](https://tw.ecob.okinawa/okinawa-noodle-kinchichi-onna-tw/) / [將軍漢堡地圖](https://www.google.com/maps/search/?api=1&query=SHOGUN%20BURGER%20Onna) / [將軍漢堡介紹](https://www.markting.com.tw/577/)）

### Day 5｜6/3（三）渡假飯店放空，美國村補位

- 住宿：沖繩殘波岬美爵度假酒店（Grand Mercure Okinawa Cape Zanpa Resort / グランドメルキュール沖縄残波岬リゾート）
- 早餐準備：6/2 恩納／讀谷周邊便利店買好。
- 雨天備案：雨天以飯店室內設施、餐廳、休息為主；只有 5/31 沒去成美國村時才補位。

#### 時間軸

- **上午**：飯店泳池、沙灘、親子放空。（[飯店地圖](https://www.google.com/maps/search/?api=1&query=Grand%20Mercure%20Okinawa%20Cape%20Zanpa%20Resort)）
- **中午**：飯店內或讀谷／恩納周邊午餐。
- **下午**：回房午睡或繼續飯店設施。
- **傍晚**：若 5/31 美國村受雨影響，這天補美國村；否則維持純放鬆。（[美國村](https://www.google.com/maps/search/?api=1&query=American%20Village%20Okinawa)）

#### 三餐與採買

- **早餐**：前一晚便利店或飯店附近採買。
- **午餐**：蒜香蝦餐廳、金月沖繩麵，或飯店內解決。（[蒜香蝦地圖](https://www.google.com/maps/search/?api=1&query=THE%20GARLIC%20SHRIMP%20Okinawa) / [蒜香蝦介紹](https://www.markting.com.tw/564/) / [金月地圖](https://www.google.com/maps/search/?api=1&query=Kinjichi%20Soba%20Onna) / [金月介紹](https://tw.ecob.okinawa/okinawa-noodle-kinchichi-onna-tw/)）
- **晚餐**：飯店餐廳；若補美國村，選加州廚房或和牛咖啡 Kapuka。（[加州廚房地圖](https://www.google.com/maps/search/?api=1&query=THE%20CALIF%20KITCHEN%20Okinawa) / [加州廚房介紹](https://gogojp.tw/the-calif-kitchen-r/) / [Kapuka 地圖](https://www.google.com/maps/search/?api=1&query=WaGyu%20Cafe%20Kapuka) / [Kapuka 介紹](https://fupo.tw/blog/post/wagyu-cafe-kapuka)）

### Day 6｜6/4（四）回那霸，市區採買

- 住宿：那霸單軌沿線住宿（建議旭橋／縣廳前／小祿／赤嶺）
- 早餐準備：6/3 恩納／讀谷周邊便利店買好。
- 雨天備案：市區日受雨影響小；下雨就選新都心、DFS、商場、餐廳，縮短國際通戶外步行。

#### 時間軸

- **上午**：退房後自駕回那霸，飯店寄放行李或入住。
- **下午**：新都心（Omoromachi / おもろまち）、DFS 沖繩或國際通擇一。（[新都心](https://www.google.com/maps/search/?api=1&query=Omoromachi%20Naha) / [DFS](https://www.google.com/maps/search/?api=1&query=T%20Galleria%20Okinawa%20by%20DFS) / [國際通](https://www.google.com/maps/search/?api=1&query=Kokusai%20Dori%20Naha)）
- **晚上**：那霸市區晚餐、採買、整理行李。

#### 三餐與採買

- **早餐**：前一晚採買。
- **午餐**：可納滋咖啡新都心店或商場簡餐。（[Konazu 地圖](https://www.google.com/maps/search/?api=1&query=Konazu%20Coffee%20Naha%20Shintoshin) / [Konazu 參考](https://www.google.com/maps/search/?api=1&query=Konazu+Coffee+Naha+Shintoshin)）
- **晚餐**：國際通屋台村、牛排館 88、豬肉蛋飯糰牧志市場店。（[屋台村地圖](https://www.google.com/maps/search/?api=1&query=Kokusai%20Dori%20Yatai%20Mura) / [屋台村介紹](https://mimigo.tw/okinawa-yatai/) / [牛排館88地圖](https://www.google.com/maps/search/?api=1&query=Steak%20House%2088%20Kokusai%20Dori) / [牛排館88介紹](https://twobunny.tw/steak-house-88/) / [Potama 地圖](https://www.google.com/maps/search/?api=1&query=Potama%20Makishi%20Market) / [Potama 介紹](https://www.gltjp.com/zh-hant/article/item/21034/)）

### Day 7｜6/5（五）南部收尾，文化王國，知念岬，Costco

- 住宿：那霸單軌沿線住宿（建議旭橋／縣廳前／小祿／赤嶺）
- 早餐準備：6/4 那霸市區便利店買好。
- 雨天備案：小雨保留文化王國與 Costco，知念岬縮短；大雨取消知念岬，文化王國只跑玉泉洞與室內區。

#### 時間軸

- **上午**：沖繩世界文化王國（Okinawa World / おきなわワールド），停留 2.5 到 4 小時。（[地圖](https://www.google.com/maps/search/?api=1&query=Okinawa%20World) / [中文攻略](https://okinawa.letsgojp.com/archives/757370/)）
- **中午**：南城市景觀午餐。
- **下午**：晴天短停知念岬公園（Cape Chinen Park / 知念岬公園），再去 Costco。（[知念岬](https://www.google.com/maps/search/?api=1&query=Cape%20Chinen%20Park) / [知念攻略](https://mimihan.tw/chinenmisaki-park/) / [Costco](https://www.google.com/maps/search/?api=1&query=Costco%20Okinawa%20Nanjo%20Warehouse) / [Costco 遊記](https://ksk.tw/okinawa-costco/)）
- **下午後段**：好市多沖繩南城倉庫店採買晚餐與隔天早餐。（[Costco](https://www.google.com/maps/search/?api=1&query=Costco%20Okinawa%20Nanjo%20Warehouse) / [Costco 遊記](https://ksk.tw/okinawa-costco/)）
- **雨天**：知念岬取消；文化王國縮短成玉泉洞與室內區；Costco 保留。

#### 三餐與採買

- **早餐**：前一晚便利店早餐。
- **午餐**：海景香料餐廳 Kurukuma 或海景咖啡 Yabusachi。（[Kurukuma 地圖](https://www.google.com/maps/search/?api=1&query=Cafe%20Kurukuma%20Okinawa) / [Kurukuma 介紹](https://rocky.tw/cafe-kurukuma/) / [Yabusachi 地圖](https://www.google.com/maps/search/?api=1&query=Cafe%20Yabusachi%20Okinawa) / [Yabusachi 介紹](https://www.totalokinawa.com/cafe-yabusachi/)）
- **晚餐**：Costco 熟食：壽司、烤雞、沙拉、Pizza、麵包。（[Costco 地圖](https://www.google.com/maps/search/?api=1&query=Costco%20Okinawa%20Nanjo%20Warehouse) / [Costco 遊記](https://ksk.tw/okinawa-costco/)）
